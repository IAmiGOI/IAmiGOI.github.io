Speaker Colors paints each character's **dialogue** in their own colour. Detection is local and it **never changes the text sent to the model** — only how it looks to you.

The module only matches text against the **cast you enter** (names and pronouns). It does not guess who is speaking.

## Set it up

<ol class="steps">
<li markdown="1">
### Switch it on
Modules card → **Speaker Colors**.
</li>
<li markdown="1">
### Add your cast
Press **Add character**: enter a name and a gender, then pick a colour. Each character on the list has its own colour.
</li>
<li markdown="1">
### Save as a preset (optional)
**Save current cast as preset** stores the list under a name. Use **Apply** to bring it back and **Delete** / **Remove** to manage presets — handy for recurring casts.
</li>
</ol>
