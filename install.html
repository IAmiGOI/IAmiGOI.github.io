Install ST Module Engine

Two ways. The first takes thirty seconds and updates itself; the second is for offline or manual setups.

You need: a working SillyTavern (a recent release) and a browser. A model connection is needed for most features — the setup guide inside the engine helps with that on first launch.

Method 1 — from inside SillyTavern recommended

  1. Open the installer

    In SillyTavern click the Extensions icon (stacked cubes) → Install extension.

  2. Paste the repository link

    https://github.com/IAmiGOI/Module-Engine

    Leave the branch empty and press Install for all users (or Install just for me).

  3. Reload the page

    The loading screen now shows ST × ME. The engine's dock appears on the right edge of the screen — hover it to open the panel.

Method 2 — from a release ZIP

  1. Download

    Download latest release

  2. Unzip into the extensions folder

    Create a folder named Module-Engine and put the contents of the ZIP in it, so that manifest.json sits directly inside:

    SillyTavern/public/scripts/extensions/third-party/Module-Engine/manifest.json

    Installing only for your user? Use SillyTavern/data/<your-user>/extensions/Module-Engine/ instead.

  3. Restart and reload

    Restart SillyTavern if it was running, then reload the page.

First launch

  1. Meet Mea

    On the very first start the built-in guide opens by itself and walks you through a short checklist.

  2. Connect a model

    Choose Use SillyTavern's current connection for the quickest start, or enter your own API key and endpoint. See Model connections.

  3. Turn modules on

    Open Modules and switch on what you want — Tracker and RP Time are good first picks.

Updating

The engine checks for new versions itself: open the Updates card on the settings screen and press install. You can also use SillyTavern's own extension manager, or download the newest ZIP and replace the folder (your settings are stored separately and are kept).

Uninstalling

Open Extensions → Manage extensions, find ST Module Engine and remove it — or delete the Module-Engine folder. Your chats and characters are never touched.

Something went wrong?

  • No dock after reload — check that manifest.json is directly inside the Module-Engine folder (not one level deeper) and that the extension is enabled in the extension manager.
  • Features do nothing — a model connection is missing or down. See Troubleshooting.
  • Still stuck? Open an issue on GitHub.
