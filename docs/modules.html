Modules

Modules at a glance

NeedsMost modules need a model connection
Find itEngine panel → Modules

Switch modules on and off in the Modules card. Each module's own settings appear there once it is on. Most modules need a working model connection.

Good first modules: Tracker — watch values like health or mood update by themselves — and RP Time — an in-world clock.

Story awareness

Tracker · module.tracker Named values that a model keeps up to date and publishes as macros.

RP Time · module.time Works out the story's time from the chat and shows a badge.

Notebook · module.notebook Private working memory the AI writes to and reads back.

Secrets · module.secrets Hidden facts tagged with who knows them.

Writing quality

Post-Turn Processor · module.postprocess Rewrites every fresh reply through a chain of passes.

Speaker Colors · module.speakerColors Colours each character's dialogue by who speaks.

Atmosphere

Scene Painter · module.scenePainter Paints the current scene into a picture.

Music · module.music Plays background music that matches the scene.

Map · module.map A floating world map with distances and travel time.

The module.* ids are the names the engine uses internally (for example in the guide's actions). You never need to type them.
