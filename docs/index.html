ModulesEvery feature, step by step.

Modules at a glance

Every module on one page, with what it is for and where to read more.

Tracker

Keep named values — health, mood, location — up to date automatically and use them in prompts.

RP Time

An in-world clock worked out from the conversation, shown under replies.

Post-Turn Processor

Rewrite every fresh reply through a chain of independent passes — grammar, clichés, style, continuity.

Scene Painter

Turn the current scene into a picture, with free and paid image backends.

Music

Ready-made background music from the Module Engine music library, chosen by the meaning of the scene.

Speaker Colors

Colour every character's dialogue so you can see who is talking.

Map

A floating full-screen world map with regions, distances and travel time.

Notebook & Secrets

Working memory for plans and goals, and hidden facts that only some characters know.

Memory & promptsLong-term memory and full control of the request.

Chat Summary

Fold old messages into leveled summaries so very long chats still fit the context.

Memory graph

A mind-map of people, places and facts built from your chat, in its own window.

Lorebook & Macros

See and edit the World Info the engine uses, and use live values anywhere with {{macros}}.

Prompt Manager

Build the request that goes to the model — order, conditions, cache, chain-of-thought and text rules.

Interface & dataThe look of the engine, and keeping your data safe.

Chat Viewport & desktop

An experimental replacement for SillyTavern's chat view, and the desktop home screen.

Sync, backup & updates

Export your configuration, sync between devices, update the extension and manage backgrounds.
