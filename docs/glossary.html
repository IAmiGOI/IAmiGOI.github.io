Glossary

Term Meaning
Module A feature you switch on or off: Tracker, RP Time, Music…
Core One of the engine's own parts: model connections, memory, sync, prompt pipeline, UI
Card A panel of the engine's main screen, usually one per Core or module
Model connection / worker A model the engine may call for its side jobs: format, endpoint, key, model
Mea The built-in guide with her own chat
Dock The pill on the right edge of the screen that opens the engine and its windows
Macro A {{placeholder}} replaced with a live value when a prompt is built
Poll One update request a tracker sends to its model
Pass One rewrite step in the Post-Turn Processor
Protected window The newest messages that summaries never fold
Fold Turning many messages into one summary (originals are hidden, not deleted)
Embedding A numeric "meaning fingerprint" of text; used locally to match music, memories and lorebook entries by meaning
Pipeline The path a generation takes through the engine: hold, rewrite, cancel
PM Prompt Manager
CoT Chain-of-thought — hidden thinking steps before an answer
Jev A small classifier that estimates the chance a statement is true; used in PM conditions
Prefix cache A provider's saving for the unchanged start of a request; changes early in the prompt cost it
Chat Viewport The engine's experimental replacement for the chat view
